## What it is

Aliasist Files‑Abductor is a cross‑platform desktop tool for downloading files from YouTube and direct URLs (built with Python + yt‑dl tooling). The release assets include AppImage, Snap, and a Windows installer.

## Download

Releases: https://github.com/aliasist/aliasistabductor/releases

Select the asset matching your platform (AppImage, Snap, or Windows installer). The screenshots above show the UI and expected behavior — review them before downloading.

## Quick start (Linux AppImage)

1. Download `Aliasist.Files.Abductor-*.AppImage` from Releases.
2. Make executable: `chmod +x Aliasist.Files.Abductor-*.AppImage`
3. Run: `./Aliasist.Files.Abductor-*.AppImage`
