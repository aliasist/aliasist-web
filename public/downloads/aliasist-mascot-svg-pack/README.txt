FORMAT NOTE
These concepts were created as detailed 3D raster artwork. Each SVG is a
self-contained scalable SVG document with the original lossless artwork
embedded inside it. This preserves the approved lighting, gradients, and
detail without requiring any external image file.

The files can be opened in browsers and common SVG-capable design software.
They are not manually redrawn path-based vector illustrations. A production
vector identity should be redrawn from the selected mascot after approval.
